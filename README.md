# Assembly Projects (FASM)
This repository contains my studies and projects in x86-64 Assembly language using FASM on Linux.
I write all my code manually in Neovim to build a solid foundation in low-level programming. My goal is to progress from basic logic to more complex system applications over time.
These codes are shared for educational purposes. If they help or inspire anyone else learning Assembly, I would be very happy.
I am always open to constructive feedback and technical discussions to improve my coding skills.
## 🛠 Setup & Installation
To run these projects, you need to have **Flat Assembler (FASM)** installed on your system. Here is how you can install it on various Linux distributions:
### 1. Debian / MX Linux / Ubuntu
```bash
sudo apt update
sudo apt install fasm

```
### 2. Arch Linux
```bash
sudo pacman -S fasm

```
### 3. Fedora
```bash
sudo dnf install fasm

```
## 🚀 How to Compile and Run
After installing FASM, follow these steps to compile and execute any .asm file in this repository:
 1. **Assemble the code:**
   fasm your_file.asm
 2. **Set execution permission:**
   chmod +x your_file
 3. **Run the program:**
   ./your_file
